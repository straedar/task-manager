# Stockmap

Минимальная карта склада: рисуешь стеллажи мышью, данные в **SQLite 3**.

## Стек

- React + TypeScript + Vite
- React-Konva
- Fastify + SQLite 3 (`node:sqlite`, файл `data/stockmap.db`)

## Объекты на плане

Стеллаж, стена, дверь, стол, стул — рисуются сверху. У стеллажа можно войти внутрь к полкам.

## Режимы

- **Сборка** — рисовать карту на компьютере (инструменты, перенос, ресайз)
- **Обход** — телефон: панорама, pinch-zoom, вход в стеллаж, наполнение полок

На узком экране по умолчанию включается «Обход».

## Запуск

```bash
npm install
npm run dev
```

На этом компьютере: http://127.0.0.1:5173  

С телефона в той же Wi‑Fi: адрес из терминала `Network:`  
(например `http://192.168.x.x:5173`)

API проксируется через Vite, база: `data/stockmap.db`
